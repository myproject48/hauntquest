## Original content and illustrations

- `assets/content/story.json`: premise, characters, intro, flags, journals, evidence and endings.
- `assets/content/rooms.json`: five rooms, object descriptions and clue inscriptions.
- `assets/content/items.json`: ten item/clue definitions.
- `assets/content/puzzles.json`: sixteen authored deterministic puzzles and their hints.
- `assets/content/choices.json`: seven linked dialogue nodes and branching choices.

All characters (Tallow, Ottoline Vask, Wren Dabney, Edric Maul and the Echo), places
and story are original. Scenes, objects, item illustrations, portraits, puzzle
instruments, sigils and ending illustrations are drawn in code with `CustomPainter`
under `lib/core/painting/`. No stock art or generated image service is used.

## Original audio (20 local WAV files)

Generated by `tool/generate_audio.py` using only Python's standard library,
oscillators, envelopes and seeded noise. No recordings, music, samples or stock
packs are used. Every file is 16 kHz, mono, 16-bit PCM and uses the project MIT license.

| Files under `assets/audio/` (all `.wav`) | Purpose |
| --- | --- |
| ambient_hall, ambient_library, ambient_workshop, ambient_clocktower, ambient_vault | Five room soundscapes |
| pickup, unlock, success, failure, footstep, discovery, chapter, interact | Eight interaction cues |
| ending_release, ending_seal, ending_guardian | Three ending reveals |
| echo_220, echo_330, echo_440, echo_550 | Four optional pitch cues with visual/written equivalents |

Regenerate with `python3 tool/generate_audio.py`. Gameplay never downloads audio.

## Platform assets

`tool/icon/generate_launcher_icon_test.dart` renders original moonlit-manor artwork:

- Android: `android/app/src/main/res/mipmap-*/ic_launcher*.png`; adaptive icon XML
  under `mipmap-anydpi-v26/`, and original palette-based launch XML/colors/styles.
- iOS: all `ios/Runner/Assets.xcassets/AppIcon.appiconset/*.png`.
- macOS: all `macos/Runner/Assets.xcassets/AppIcon.appiconset/*.png`.
- Web: `web/favicon.png` and `web/icons/*.png`, including maskable variants.
- Windows: `windows/runner/resources/app_icon.ico`, PNG-compressed original artwork.

Regenerate with `flutter test tool/icon/generate_launcher_icon_test.dart`.
Transparent iOS launch placeholders remain unchanged Flutter template assets
(BSD-3-Clause), verified against the installed SDK template. Platform scaffolding
also derives from Flutter's BSD-licensed app template.

## Fonts and UI icons

The game requests platform serif fonts (Georgia where available); it bundles no
proprietary font files. Flutter's Material Icons are Apache-2.0 and carry the
SDK's notices. `cupertino_icons` is an unused MIT template dependency. No third-party
illustration, voice recording, paid media or remotely hosted font is included.
